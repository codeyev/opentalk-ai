# Roadmap

Roadmap items are goals, not promises or release dates. A ticked item is
implemented; whether it has been verified, and on which system, is
recorded in `docs/KNOWN_LIMITATIONS.md`.

## MVP

-   [x] Tauri desktop shell for macOS and Windows
-   [x] Explicit microphone/system-audio capture
-   [x] Live transcription
-   [x] Translation panel
-   [x] Three contextual reply suggestions
-   [x] Provider settings and secure credential storage
-   [x] Privacy-first defaults

## Language and accessibility

-   [x] Arabic RTL layout
-   [x] Arabic tashkeel preferences
-   [x] English, Azerbaijani, Russian UI localization
-   [ ] Additional UI languages through community translations
-   [x] Glossary and domain vocabulary

## Providers

-   [x] First cloud transcription provider
-   [x] First translation/reply provider
-   [x] Ollama-compatible reply provider
-   [x] Local transcription evaluation and adapter
-   [x] Optional TTS adapter
-   [x] Spoken translations of the other side, with a choice of voice
-   [ ] Speaking the user's translated words to the other side (needs a
    virtual microphone)

## Release quality

-   [ ] Signed/notarized macOS distribution
-   [ ] Windows installer and signing guidance
-   [ ] Auto-update design and security review
-   [ ] Accessibility audit
-   [ ] Contributor documentation
-   [ ] Public demo and website page
