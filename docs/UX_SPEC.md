# UX Specification

## Visual direction

-   Professional, calm, compact desktop utility.
-   Avoid generic AI gradients, excessive glow, decorative robot
    imagery, and noisy dashboards.
-   Strong typography, clear spacing, restrained accent color.
-   Dark and light themes.
-   Floating compact mode plus full dashboard.

## Live workspace

Header: - OpenTalk AI name/logo - session state: Idle / Listening /
Processing / Error - elapsed time - settings button

Audio controls: - microphone source selector - system audio
toggle/source selector - explicit Start/Stop - clear capture indicator

Conversation: - source transcript - translated transcript - language
labels - timestamps - partial transcript visually differentiated from
final transcript

Reply suggestions: - up to three cards - tone label - suggested reply in
target language - translated meaning - copy and edit controls - refresh
suggestions - warning when facts are missing or confidence is low

## Arabic and RTL

-   Use correct RTL direction and Arabic-capable fonts.
-   Do not reverse punctuation or Latin numbers incorrectly.
-   Preserve mixed Arabic/Latin technical strings.
-   Make tashkeel setting visible.
-   Ensure copy action copies logical text order.

## Accessibility

-   Keyboard-only operation
-   Visible focus states
-   Screen-reader labels
-   Avoid relying on color alone for recording state
-   Respect reduced motion settings
