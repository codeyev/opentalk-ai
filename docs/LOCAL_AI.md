# Local AI

OpenTalk AI can run translation and reply suggestions on a model on your
own computer, through [Ollama](https://ollama.com). Text handled this way
never leaves the machine.

## Using a local model

1.  Install Ollama and start it.
2.  Install a model yourself, for example `ollama pull qwen3.5:9b`.
    OpenTalk AI lists the models Ollama already has and never downloads
    one.
3.  In OpenTalk AI, open Providers. Under Local AI, check the connection
    and choose the model.
4.  Under Translation and Reply suggestions, choose "Ollama · on this
    computer" and turn the feature on.

Two rules are enforced in code:

-   The Ollama address must be on this computer (`localhost`,
    `127.0.0.1`, or `[::1]`, plain `http`, no path). Any other address is
    refused, and requests bypass any system proxy.
-   A model that is not installed is reported as missing. Nothing is
    downloaded.

## Local-only mode

Providers has a "Local-only mode" switch. With it on:

-   Cloud providers cannot be chosen in the interface.
-   The app core refuses to start a session that would use a cloud
    provider, whatever the interface sent.

With a Whisper model chosen for transcription and an Ollama model for
translation and replies, the whole pipeline runs in local-only mode.
Downloading a Whisper model is also refused in this mode, since it
contacts a download server; download first, or copy a model file in.

## What to expect

Measured on 2026-11-11 on an Apple M5 with 16 GB of memory, Ollama
0.40.14, model `qwen3.5:9b` (7.6 GB on disk), one request each:

| Task | Time |
| ---- | ---- |
| Translate one sentence, English to Russian, model not yet loaded | 4.4 s |
| Three reply suggestions | 5.2 s |

-   The translation was correct and kept "14" and "1 200" (written the
    Russian way). It rewrote "USD" as "долларов США" despite the rule to
    keep amounts as they are.
-   Asked "How much is it?" with no price in the business context, all
    three suggestions asked a clarifying question and none invented a
    price.
-   With the model's thinking mode left on, the same requests took 88 s
    and 62 s. The app turns thinking off for this reason.

These are single measurements on one machine with one model, not a
benchmark. A model needs about as much free memory as its size on disk,
and quality varies with the model and the language. No language pair has
been verified beyond the one sentence above.

## Local transcription with Whisper

The Whisper speech recognition engine (whisper.cpp) is compiled into
OpenTalk AI. It needs a model file and nothing else: no other program,
no server, no account.

### Getting a model

Open Providers, Local transcription.

-   **Download:** press Download next to a model. This is the only time
    the app fetches a model. The file comes from the whisper.cpp model
    repository on Hugging Face and is checked against its published
    SHA-256 and size; a file that does not match is deleted. Downloading
    is refused in local-only mode.
-   **Bring your own:** copy any Whisper model in `ggml` format, named
    `ggml-<name>.bin`, into the models folder shown on that screen.

| Model | Download size | Notes |
| ----- | ------------- | ----- |
| tiny | 78 MB | Fastest, least accurate |
| base | 148 MB | |
| small | 488 MB | |
| large-v3-turbo | 1.6 GB | Most accurate of these |

The models are multilingual. They are published by OpenAI under the MIT
license; whisper.cpp is MIT licensed too. A model needs roughly as much
memory as its file size.

### How it behaves

-   Whisper transcribes a finished utterance, not a live stream. Text
    appears when the speaker pauses; there is no partial text while they
    speak.
-   With the spoken language set to automatic, Whisper detects it and
    the segment is labelled with what it detected.
-   Audio is processed in memory and never written to disk.

### Measured

On 2026-11-11 on an Apple M5 with 16 GB of memory, with the
`large-v3-turbo` model and the engine built into the app (debug build),
on speech generated by the macOS system voices:

| Language | Audio length | Time to transcribe | Result |
| -------- | ------------ | ------------------ | ------ |
| English | 8.9 s | 2.3 s | Every word correct; language detected |
| Russian | 5.4 s | 2.0 s | Every word correct ("займёт" written "займет"); language detected |
| Arabic | 5.7 s | 2.0 s | Every word correct; language detected |

Loading the model took 0.6 s.

Caveats: the speech was synthetic, clear, and free of noise, one
sentence per language, on one machine. Real conversations with accents,
cross-talk, and poor audio will do worse. Smaller models were not
measured. Azerbaijani was not tested. Nothing was measured on Windows,
where the engine has not yet been built.
